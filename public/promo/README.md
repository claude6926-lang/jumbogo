# JUMBO GO — เว็บไซต์ประชาสัมพันธ์

เว็บไซต์ภาษาไทย HTML, CSS, JavaScript ล้วน ไม่มีขั้นตอน build และไม่มี dependency ภายนอก ใช้รูปที่ได้รับทั้ง 5 รูปและฟอนต์ Kanit ในโฟลเดอร์ assets

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง หรือให้ static web server ให้บริการโฟลเดอร์นี้ หากใช้ Next.js ของโครงการเดิม เปิด `/promo/index.html`

- `index.html`: เนื้อหาเว็บไซต์และแบบฟอร์ม
- `styles.css`: ธีมดำ แดง ขาว และ responsive layout
- `script.js`: เลือกรถ เมนูมือถือ สรุปแผน และคัดลอกข้อความ
- `assets/`: รูปภาพและฟอนต์ที่ใช้ในเว็บ

แบบฟอร์มเตรียมข้อมูลในเบราว์เซอร์เท่านั้น ไม่ส่งข้อมูล ไม่เก็บข้อมูลถาวร และไม่สร้างการจองจริง ไม่ได้กำหนดราคา เบอร์โทร LINE หรือน้ำหนักบรรทุกที่ยังไม่ได้รับการยืนยัน หากต้องการรับคำขอจริงต้องเชื่อมช่องทางติดต่อหรือ API ของระบบก่อนใช้งานส่วนนี้

สามารถย้ายทั้งโฟลเดอร์ไปยัง static hosting ใดก็ได้ โดยคงโครงสร้าง assets ไว้ ฟังก์ชันคัดลอกใช้ HTTPS หรือ localhost; หากไม่ได้รับอนุญาต เว็บไซต์จะแสดงข้อความให้เลือกคัดลอกด้วยตนเอง
